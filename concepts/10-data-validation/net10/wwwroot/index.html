Diferencial Técnico do .NET 10: O atributo [ApiController] intercepta a requisição antes mesmo de entrar no método da Controller. Quando o modelo é inválido, o framework devolve automaticamente a estrutura application/problem+json definida pela especificação RFC 7807 e RFC 9457, contendo títulos padronizados, códigos numéricos e o campo traceId para rastreabilidade de suporte, sem exigir repetição de código com if (!ModelState.IsValid).
